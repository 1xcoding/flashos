# FlashOS Manager

FlashOS Manager — это инструмент для управления операционной системой FlashOS на USB-устройствах.

## Версии

- **Linux / Bash**: `flashos.sh` (версия 0.4.0)
- **Windows / PowerShell**: `flashos.ps1` (версия 0.3.1-ps)

> Всё, что описано ниже в разделе «Новое в 0.4.0», относится к Linux-версии.
> Windows-версия пока остаётся каркасом: она находит флешку с FlashOS и показывает
> информацию о ней, остальные пункты меню — заглушки.

## Возможности

- Обнаружение USB-устройств
- Обнаружение и установка FlashOS
- Форматирование в exFAT
- Зашифрованное основное хранилище
- Режим хранилища (Vault Mode)
- Резервное копирование
- Диагностика
- Настройки
- Обновление до последней версии с GitHub
- Удаление FlashOS
- Интерактивный интерфейс (клавиатура)

## Новое в 0.4.0

### 1. Автоблокировка и мгновенная блокировка

- **Автоблокировка при бездействии**: `Settings → Автоблокировка` — выключена, 1, 5, 10 или 30 минут.
  Срабатывает в меню, на экранах «Нажми Enter» и в строках ввода. По умолчанию выключена.
- Если в этот момент какая-то программа работает с файлами хранилища, автоблокировка
  не обрывает её, а ждёт, пока хранилище освободится.
- **Клавиша `L`** в любом меню блокирует FlashOS сразу.

### 2. Журнал событий

- Входы, неудачные попытки ввода пароля, блокировки, Backup, операции с Vault, обновления
  записываются в `.flashos/logs/flashos.log`. Просмотр: `Diagnostics → Журнал событий`.
- После входа менеджер предупреждает, если с прошлого раза кто-то вводил неверный пароль.
- Журнал лежит в незашифрованной части флешки, поэтому в него пишутся только время и тип
  события — без имён файлов, Vault и путей. Выключить или очистить: `Settings`.

### 3. Recovery: защита от потери ключей

- Файл ключей хранилища (`gocryptfs.conf`) копируется в `.flashos/recovery/keys` после
  каждого удачного входа. Если оригинал повредится, данные можно вернуть:
  `Recovery → Восстановить ключи из копии`. Копия зашифрована тем же паролем.
- `Проверить шифрованное хранилище (fsck)` — проверка целостности всех файлов
  средствами gocryptfs (в `Recovery` и в `Diagnostics`).

### 4. Смена паролей

- Главный пароль: `Settings → Сменить главный пароль`.
- Пароль Vault: `Vault Mode → Управление Vault → Сменить пароль`.

### 5. Управление Vault

- Переименование, просмотр размера и удаление Vault
  (удаление — только после ввода названия Vault).

### 6. Backup с проверкой

- При создании Backup считаются контрольные суммы SHA-256 по оригиналу, и копия сразу
  сверяется с ними.
- `Проверить Backup` — убедиться, что копия не испортилась со временем.
- `Восстановить Backup` — в новую папку на компьютере (по умолчанию `~/FlashOS-Restore`),
  существующие файлы не перезаписываются.
- `Удалить Backup`, список с размерами, проверка свободного места до начала копирования.

### 7. Файлы

- Поиск по части имени, импорт файла или папки в хранилище, «Что занимает место».
- Пути можно вводить с `~`, в кавычках и перетаскиванием из файлового менеджера.

### 8. Несколько флешек и безопасное извлечение

- Если подключено несколько флешек с FlashOS, менеджер предлагает выбрать.
- «Сменить USB» заново ищет флешки.
- `Безопасно извлечь` — блокирует FlashOS, размонтирует флешку и отключает её питание.
  Работает и тогда, когда менеджер запущен с самой флешки.

### 9. Обновления

- Раз в сутки менеджер в фоне проверяет, не вышла ли новая версия, и показывает отметку
  в главном меню. Отключается: `Settings → Проверка обновлений при запуске`.
- `Recovery → Откатить менеджер на прошлую версию` — возврат к версии, сохранённой
  при обновлении.
- Обновления берутся из `1xcoding/flashos`.

### 10. Командная строка

```
./flashos.sh --help       справка
./flashos.sh --version    версия
./flashos.sh --status     подключённые флешки FlashOS и их состояние
./flashos.sh --lock       немедленно заблокировать открытое хранилище
./flashos.sh --doctor     проверить зависимости
./flashos.sh --no-color   без цветов (то же делает переменная NO_COLOR)
```

`--lock` можно вызвать из другого терминала или назначить на сочетание клавиш.

### Исправления

- **Потеря данных при блокировке.** В 0.3.0, если в момент блокировки или выхода какая-то
  программа работала с файлами хранилища или Vault, менеджер удалял эти файлы.
  Теперь при блокировке ничего не удаляется; занятое хранилище отключается принудительно
  с предупреждением.
- `Esc` и `Q` теперь действительно возвращают назад. В 0.3.0 `Esc` в списке флешек при
  установке открывал экран форматирования первой флешки.
- `Ctrl+C` и закрытие терминала блокируют FlashOS и завершают программу.
- Команда установки зависимостей подсказывается для Arch, Debian/Ubuntu, Fedora и openSUSE.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `↑` `↓` | выбор пункта |
| `Enter` | открыть |
| `Esc`, `Q` | назад |
| `L` | заблокировать FlashOS (когда хранилище открыто) |

## Что хранится на флешке

| Путь | Назначение |
| --- | --- |
| `.flashos/data` | зашифрованное хранилище (внутри — файлы, Vault и Backup) |
| `.flashos/recovery/keys` | копия ключей хранилища |
| `.flashos/recovery/manager-backups` | прошлые версии менеджера |
| `.flashos/logs/flashos.log` | журнал событий |
| `.flashos/system/settings` | настройки этой флешки |
| `.flashos/flashos.sh` | менеджер |

## Установка и запуск

### Для Linux (Bash)

```bash
chmod +x flashos.sh
./flashos.sh
```

### Для Windows (PowerShell)

1. Откройте PowerShell от имени администратора.
2. Перейдите в папку с файлом:
   ```powershell
   cd C:\путь\к\папке
   ```
3. Запустите скрипт:
   ```powershell
   .\flashos.ps1
   ```

## Требования

- **Linux**: `lsblk`, `findmnt`, `udisksctl`, `gocryptfs`, `fusermount3`, `mkfs.exfat`, `curl`, `bash`, `jq`.
  Проверить: `./flashos.sh --doctor`
- **Windows**: PowerShell 5.1+, права администратора
